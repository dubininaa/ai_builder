# AI Builder

Сайт-портфолио Анастасии Дубининой: работа с ИИ, вайбкодинг и образовательные проекты.

На сайте представлены три кейса:

- Instagram-аналитик с данными аккаунта и рекомендациями по контенту.
- Telegram-бот «ИИшница» с базой знаний и Студией для подготовки публикаций.
- Практико-рефлексивные тренажёры для курса по управлению образовательными проектами.

Примеры интерфейсов и описания инструментов открываются из карточек проектов. Также на сайте есть ответы на вопросы, профессиональный опыт, публикация в Unicraft и контакты.

## Запуск

Сайт работает на HTML, CSS и JavaScript. Установка зависимостей и сборка не требуются.

Из корня репозитория запустите локальный сервер:

```bash
python3 -m http.server 8080 --directory dist
```

Откройте `http://localhost:8080/`.

## Структура

| Путь | Содержание |
| --- | --- |
| `dist/index.html` | Структура страницы и тексты |
| `dist/styles.css` | Оформление и адаптивная вёрстка |
| `dist/script.js` | Открытие и закрытие примеров проектов |
| `dist/assets/` | Скриншоты проектов |

## Редактирование

- Тексты, ссылки и карточки проектов: `dist/index.html`.
- Цвета, шрифты и расположение элементов: `dist/styles.css`.
- Работа окон с примерами: `dist/script.js`.
- Изображения: `dist/assets/`.

## Размещение

Для публикации используйте содержимое папки `dist` на статическом хостинге. Точкой входа служит `dist/index.html`.
